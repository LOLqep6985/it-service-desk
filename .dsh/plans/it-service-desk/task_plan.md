# 任务计划：it-service-desk

## 目标

构建「医院多院区 IT 报修/维修/报销三端系统」：
- 科室报修端（免登录）提交极简报修单 → 管理员后台派单生成工单 → 维修人员端到场处理并签字确认 → 月度报销闭环。
- 简历级 Java 全栈项目（Java 17 / Spring Boot / MyBatis-Plus / MySQL / Redis可降级 / Vue3）。

## 关键业务约束

- 三端：科室报修端（免登录、工作手机绑定科室）、管理员后台端（PC）、维修人员端（手机）。
- 报修单 ≠ 工单：科室提交报修单 → 管理员受理派单 → 转为工单。
- 科室端字段极简：科室自动带出；只填 报修人姓名、宽泛设备名称、照片、简单描述；不填具体地点/优先级。
- 科室负责人默认护士长/主任；维修完成必须护士长或指定签字人签字确认。
- 维修/耗材更换每次生成记录 + 欠条；管理员按月汇总已签字工单生成报销单，护士长签字后交财务。
- 多维修人员（含用户共 2 人）管理/调度。
- 网络异常：超时提示、失败重试、防重复提交、草稿保存（不做离线同步）。
- AI 是辅助不是卖点；技术选型服务业务问题。
